# Weather App

This is a simple web application that displays the weather for up to 5 different cities in the United States. The application fetches weather data from a public API and presents it in a user-friendly format.

## Project Structure

```
weather-app
├── src
│   ├── index.html        # Main HTML document for the web application
│   ├── styles
│   │   └── style.css     # CSS styles for the web application
│   └── scripts
│       └── script.js     # JavaScript code for fetching and displaying weather data
├── README.md             # Documentation for the project
└── .gitignore            # Files and directories to be ignored by Git
```

## Getting Started

To run the application locally, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd weather-app
   ```

2. **Open the `index.html` file** in your web browser.

3. **Ensure you have an internet connection** to fetch weather data from the API.

## Features

- Displays current weather information for up to 5 cities.
- User-friendly interface with responsive design.
- Fetches real-time data from a weather API.
